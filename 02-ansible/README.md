# 02-ansible - Docker + Nginx балансировщик

Ansible-проект, который на чистой Ubuntu VM:
- устанавливает Docker Engine и Docker Compose plugin v2;
- запускает три контейнера `no1d3d/go-info-app:1.0.0` (порты 8081–8083 на хосте);
- устанавливает nginx как балансировщик нагрузки, проксирующий запросы на три контейнера.

## Требования

- Ubuntu 24.04/26.04 VM с SSH-доступом.
- Пользователь `ansible` с настроенным SSH-ключом и беспарольным sudo.
- Ansible на управляющей машине, коллекция `community.docker`:
  ```bash
  ansible-galaxy collection install community.docker

## Обоснование выбора алгоритма балансировки

Все три контейнера - это одна и та же программа, запущенная трижды. Они одинаково быстрые и не хранят никаких данных о пользователях между запросами. Поэтому нет смысла следить, кто из них сейчас меньше загружен (least_conn) - нагрузка и так распределится ровно, и привязывать одного пользователя к одному контейнеру (ip_hash) - приложению всё равно, кто ответит, потому что оно не помнит предыдущие запросы.

Round Robin просто раздаёт запросы по очереди: первому, второму, третьему, снова первому и так далее. Это самый простой способ, и он не тратит лишних ресурсов на подсчёты.

Если один контейнер упадёт, nginx сам заметит это после первой неудачной попытки (по умолчанию - одна ошибка, потом пауза 10 секунд) и перестанет слать запросы на него. Остальные два продолжат работать, и пользователи ничего не заметят.
